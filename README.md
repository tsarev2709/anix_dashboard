# ANIX Dashboard / Anix Control

Закрытая операционная панель и управляющий контур сайта Anix.

## Что уже есть

- директорский обзор со светофором по ключевым системам бизнеса;
- карточки денег, продаж, проектов и выручки;
- демонстрационная воронка продаж;
- статусы и прогресс активных проектов;
- аудит измеримости: какие данные уже есть, считаются вручную или отсутствуют;
- приоритет подключения amoCRM, YouGile, Точки и Telegram;
- экспорт текущего среза в JSON для дальнейшего анализа и изменения модели метрик;
- Anix Control: черновики контента, версии, feature flags, управление интеграциями и метрики сайта/AI.

## Как открыть

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Для публикации можно включить GitHub Pages для корня ветки после слияния PR.

## Логика развития

1. Заменить демонстрационные значения реальными выгрузками.
2. Подключить amoCRM и YouGile первыми.
3. Добавить исторические срезы и сравнение периодов.
4. Автоматически формировать список недостающих данных и управленческих вопросов.
5. Подключить финансовые операции Точки и сигналы из Telegram.

## Структура

- `index.html` — интерфейс;
- `styles.css` — визуальная система;
- `app.js` — данные, расчёты, навигация и экспорт среза.
