# Telegram → YouGile: постановка задач по реакции 📌

## Что происходит

1. Бот запоминает новые текстовые сообщения только в тех чатах, куда его добавили.
2. Разрешённый участник ставит реакцию 📌.
3. Бот берёт исходное сообщение и до 20 предыдущих сообщений того же чата или темы.
4. Anix LLM формирует короткий заголовок и содержательное описание без выдуманных сроков и ответственных.
5. Бот сразу создаёт карточку в заданной колонке YouGile и отвечает в Telegram.
6. Повторная реакция на то же сообщение не создаёт дубль.

YouGile остаётся единственным рабочим таск-трекером. Supabase хранит 30-дневный контекст и журнал доставки для дедупликации и диагностики.

Если локальная LLM недоступна, карточка всё равно создаётся из исходного текста с предупреждением. Если YouGile недоступен, ошибка попадает в CEO-alert.

## Подключение за один раз

### 1. Telegram

1. Открыть `@BotFather`, выполнить `/newbot` и сохранить токен.
2. В `@BotFather` выполнить `/setprivacy`, выбрать нового бота и нажать **Disable**.
3. Добавить бота администратором в нужные рабочие чаты. Достаточно права читать сообщения; публикация сообщений нужна для подтверждений.

Бот не получает историю до момента добавления. Для старого сообщения нужно ответить на него командой `/task`.

### 2. YouGile

1. Создать одну колонку, например **Входящие из Telegram**.
2. Скопировать ID колонки. Это значение `YOUGILE_INBOX_COLUMN_ID`.
3. Проверить, что существующий `YOUGILE_API_KEY` в Supabase имеет право создавать задачи на этой доске.

### 3. GitHub Actions secrets

В репозитории открыть **Settings → Secrets and variables → Actions** и добавить:

| Secret | Что положить | Обязательно |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из BotFather | да |
| `TELEGRAM_WEBHOOK_SECRET` | случайная строка из букв, цифр, `_` и `-` | да |
| `YOUGILE_INBOX_COLUMN_ID` | ID входящей колонки | да |
| `ANIX_LLM_GATEWAY_SECRET` | то же значение, что `LOCAL_AI_GATEWAY_SECRET` на ПК | да |
| `YOUGILE_TASK_URL_TEMPLATE` | шаблон ссылки с `{id}`, если YouGile не возвращает URL | желательно |
| `TELEGRAM_ALLOWED_USER_IDS` | Telegram ID пользователей через запятую | позже, для жёсткого ограничения |
| `TELEGRAM_ALLOWED_CHAT_IDS` | ID разрешённых чатов через запятую | позже, для жёсткого ограничения |
| `YOUGILE_DEFAULT_ASSIGNEE_IDS` | ID исполнителей YouGile через запятую | необязательно |

Без allowlist бот работает только там, куда его добавили. Для быстрого первого запуска это нормальная граница доступа; после теста лучше добавить ID Андрея, Александры, Миши, Насти и Серёжи.

### 4. Развёртывание и тест

1. Запустить workflow **Deploy Supabase** вручную либо дождаться запуска после merge в `main`.
2. Убедиться, что локальный ПК с Ollama включён, а `https://llm.anix-ai.pro/health` отвечает успешно.
3. Написать в тестовом чате 2–3 сообщения с контекстом.
4. Поставить 📌 на сообщение с задачей.
5. Ожидаемый результат: сначала ответ «Поймал», затем карточка в YouGile и подтверждение с ID или ссылкой.

Cloudflare для dashboard-домена не участвует в приёме Telegram: webhook указывает прямо на защищённую Supabase Edge Function.

## Диагностика

- Нет ответа бота: проверить, что он администратор, Privacy Mode выключен и workflow зарегистрировал webhook.
- Бот отвечает, но карточки нет: проверить `YOUGILE_API_KEY` и `YOUGILE_INBOX_COLUMN_ID`.
- Карточка создана без переработанной формулировки: проверить ПК, Ollama, tunnel и `ANIX_LLM_GATEWAY_SECRET`.
- Нет кликабельной ссылки, только ID: задать `YOUGILE_TASK_URL_TEMPLATE`, подставив `{id}` вместо ID в реальной ссылке на карточку.
- Ошибка или обработка дольше 15 минут автоматически показывается в CEO-дайджесте.

## Ограничения первой версии

- Бот обрабатывает одну задачу на одно отмеченное сообщение.
- Фото, голосовые и файлы пока не распознаются; используется подпись, если она есть.
- Ответственный и дедлайн не назначаются по догадке. LLM сохраняет их как подсказки в журнале, но YouGile получает только подтверждённые настройки.
- Звонки Телемоста не входят в P0. Следующий безопасный шаг — загружать расшифровку в отдельный чат и отмечать нужные фрагменты той же реакцией 📌.
