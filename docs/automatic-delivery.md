# Автоматическая доставка изменений

Изменения из внутренних веток `agent/*` проходят следующий маршрут:

1. создаётся pull request в `main`;
2. GitHub Actions проверяет обязательные файлы и синтаксис JavaScript;
3. только после успешного workflow доверенный PR автоматически переводится из draft в ready;
4. PR сливается squash-методом, рабочая ветка удаляется;
5. push в `main` запускает публикацию GitHub Pages;
6. изменения в `supabase/**` дополнительно запускают миграции и деплой Edge Functions.

Автомерж не применяется к fork-репозиториям, веткам вне `agent/*` и целевым веткам, отличным от `main`.
